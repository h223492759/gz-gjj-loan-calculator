# 广州公积金买房贷款测算器 · gz-gjj-loan-calculator

面向**广州**的住房公积金买房贷款测算工具。自托管、**完全离线**、数据只存在你自己的机器上。

输入借款人信息 → 直接得到：**能不能满贷 / 需要多少商贷 / 贷款年限与月供（含还款方式差异）/ 能提取多少余额**，并把每次测算保存成可复用的记录。

> 政策口径依据广州住房公积金管理中心 2026 年现行文件，逐条在界面上给出官方出处链接，并带参数时效检测。
> 本工具不构成法律或贷款建议，实际以公积金中心与受托银行审批为准。

## 一、功能

### 输入
| 项 | 说明 |
|---|---|
| 贷款方式 | 单人申请 / 两人及以上共同申请 |
| 借款人信息 | 出生年月（**按《渐进式延迟法定退休年龄》对照表自动算退休年龄**）、身份类别（男职工 / 管理技术岗女职工 / 生产操作岗女职工）、已有公积金余额、每月缴存额 |
| 需要贷款金额 | 单位：万元 |
| 购房总价（选填） | 填了才能准确算首付与可提取额度；不填则按「贷款额 ÷（1 − 首付比例）」反推 |
| 首付比例 / 套数 / 期限 / 楼龄 | 首套、第二套；保障性住房一键切到 15% 首付；二手楼自动校验「期限 + 楼龄 ≤ 50 年」 |
| 额度上浮情形 | 育儿类（一孩 +10% / 二孩 +40% / 三孩及以上 +50%）、住房品质类（装配式或一星绿建 +10% / 二星及以上绿建 +20% /「好房子」+30%），两类可叠加、合计封顶 +80% |
| 家庭月收入（选填） | 用于硬校验「月还贷额 ≤ 家庭收入 50%」，并反推收入约束下的可贷上限 |
| 商贷利率 | 内置 5 档参考报价，**可点选、可自行添加任意利率**，方案表按不同利率并排对比 |

### 输出
1. **结论**：能满贷（纯公积金）还是需要组合贷；商贷缺口多少。
2. **额度是怎么算出来的**：每位借款人的「余额 × 10」与「月缴存额 × 到退休月数」明细，以及最终被哪一项约束卡住（额度公式 / 最高限额 / 购房总价）。
3. **买房方案对比表**：纯公积金、组合贷（每个商贷利率一行）、纯商贷，列出公积金额、商贷额、首月月供、总利息、本息合计。
4. **不同还款方式的差异**：等额本息 vs 等额本金的月供曲线与总利息差。
5. **能提取多少余额**：按月还贷期间可一次性提取的上限（= min(账户余额, 实际支付的首期房款)）、提取后留在账户里的余额、该套住房的提取总额上限。
6. **每月现金流**：月缴存额能不能覆盖公积金月供；结余能否每月转出还商贷；实际每月要自掏多少现金。
7. **风险与提示**：期限超龄、楼龄超限、月供超收入 50%、账户余额为 0 等。

### 记录
- 每次测算可**保存**；记录可**更名、复制为新、覆盖保存、删除**；
- 历史记录**一键调用**回到表单继续改，或在原记录上直接改；
- 支持**导出 / 导入备份**（JSON），换机器不丢数据。

### 界面
- 手机端、平板、电脑端自适应；深色模式自动跟随系统并可手动切换；
- 支持打印 / 存 PDF 作为方案对比稿；
- 桌面端左侧表单吸顶，滚动看结果时不用来回翻。

### 访问门禁
- **单一口令，无账号体系**：个人 / 家庭自用，全家共用同一个密码，不用注册、不用邮箱；
- 没输对密码**看不到任何内容**——界面被锁屏遮住，所有数据接口一律返回 401；
- 输对后浏览器拿到一张通行证，默认 12 小时有效；勾「记住这台设备」可延长到 30 天；
- 密码以 scrypt 加盐哈希保存，不存明文；连续输错会临时锁定来源 IP；
- 「设置」页可改密码、退出登录、一键「退出所有设备」。

## 二、部署到飞牛 NAS（Docker）

镜像由 GitHub Actions 自动构建并推送，**不需要在 NAS 上编译**。

1. 打开飞牛「Docker → 添加项目」（或 Compose 部署）；
2. 把仓库根目录的 `docker-compose.yml` 内容整个粘进去；
3. **把里面的 `ACCESS_PASSWORD` 改成自己的密码**（默认值 `gzgjj@2026` 只是占位，一定要改）；
4. 启动，然后访问 **`http://<NAS 的 IP>:8888`**，输入刚设的密码即可进入。

端口就是 `8888`，映射为宿主机 `8888` → 容器 `8888`。若 8888 被占用，只改 `docker-compose.yml` 里 `ports` 冒号左边那一半即可。

数据落在 compose 文件同级的 `./data/`（`gz-gjj.db` 记录 + `auth.json` 密码），容器删除或升级都不会丢。备份只需拷走整个 `data/` 目录，或用界面上的「导出备份」。

镜像来源二选一：

```yaml
# 默认：GHCR（免登录、无需额外配置）
image: ghcr.io/h223492759/gz-gjj-loan-calculator:latest

# 可选：Docker Hub（部分网络下 docker.io 镜像源更稳）
# 需要先在仓库 Settings → Secrets 里配置 DOCKERHUB_USERNAME / DOCKERHUB_TOKEN，
# 重跑一次 Actions 之后再把 image 换成下面这行
# image: h223492759/gz-gjj-loan-calculator:latest
```

命令行部署等价于：

```bash
git clone https://github.com/h223492759/gz-gjj-loan-calculator.git
cd gz-gjj-loan-calculator
# 先把 docker-compose.yml 里的 ACCESS_PASSWORD 改成自己的密码
docker compose up -d
```

### 升级到新版本

发布是全自动的，**不需要在 GitHub 网页上点任何按钮，也不需要人工打 tag**：

> 往 `main` 推一次代码 → GitHub Actions 依次跑「测算引擎断言 + 访问门禁断言 → 空数据卷全新部署冒烟 → 构建 amd64/arm64 镜像并推送 → 自动创建 Release」。
> 发布版本号 = **本次构建的北京时间 `vYYMMDD-HHMM`**，由 CI 内部算出，直接写在 Release 标题和镜像 tag 上。

NAS 上升级：

```bash
cd <你的 compose 目录>
docker compose pull && docker compose up -d     # 数据在 ./data，不会丢
```

或在飞牛的「Docker → 项目」里对该项目点一下「重新部署 / 更新」即可。升级后网页右上角能看到新的版本号，用它核对是否已生效。

### 访问密码怎么定 / 怎么改

| 场景 | 做法 | 结果 |
|---|---|---|
| 想要固定密码（推荐） | 在 `docker-compose.yml` 里设 `ACCESS_PASSWORD: "你的密码"`，重启容器 | **每次启动都以它为准**；网页上的「修改密码」会被禁用并提示原因 |
| 想在网页里自己管 | 不设 `ACCESS_PASSWORD`（留空或删掉），重启 | 以本地 `data/auth.json` 里的密码为准，可在「设置」页随时改 |
| 两个都没设 | 直接启动 | 首次启动**自动生成**一个 12 位随机密码，打印在容器日志里，同时写入 `data/INITIAL-PASSWORD.txt`（首次登录后可删） |
| 忘了密码 | 删掉 `data/auth.json`，重启容器 | 按当前配置重新初始化；**历史记录不受影响** |

密码说明：

- 服务端**不保存明文**，只存 scrypt 加盐哈希；改密码会自动轮换会话密钥，其他设备立刻掉线。
- 默认登录有效期 12 小时；勾选「记住这台设备」为 30 天（可在 compose 里用 `SESSION_HOURS` / `REMEMBER_DAYS` 调整）。
- 连续输错 `MAX_LOGIN_FAILS`（默认 5）次会临时锁定该来源 IP `LOGIN_LOCK_SECONDS`（默认 60）秒。
- 这是**内网自用的门禁**，不是面向公网的安全方案：它是 HTTP 明文传输。若要暴露到公网，请务必自己套一层 HTTPS 反向代理。

## 三、本地开发

```bash
npm install
npm test          # 测算引擎断言 + 访问门禁断言（纯 Node，不需要数据库）
npm start         # 默认 http://127.0.0.1:8888

# 本地起服务时想换个密码：
ACCESS_PASSWORD="mypassword" PORT=8888 npm start
```

`PORT` / `DATA_DIR` / `ACCESS_PASSWORD`（以及可选的 `SESSION_HOURS`、`REMEMBER_DAYS`、
`MAX_LOGIN_FAILS`、`LOGIN_LOCK_SECONDS`）都可以用环境变量覆盖。

政策参数集中在 **`config/guangzhou-2026.json`**，改完重启进程即可生效（不用改代码）。改参数时请同时更新 `as_of`，界面上的时效徽标会依据它判断是否需要复核。

## 四、计算口径

### 公积金可贷额度

```
可贷额度 = min(
    账户余额 × 10 + 月缴存额 × 到退休年龄月数     ← 单位缴存职工公式
    (100 万 / 200 万) × (1 + 上浮系数)            ← 上浮封顶 +80% → 180 万 / 360 万
    购房总价 × (1 − 最低首付比例)                  ← 首套及二套 20%，保障房 15%
)
月还贷额 ≤ 家庭月收入 × 50%
```

> 灵活就业人员的「日均缴存余额 × 缴存系数」公式未实现（参数文件里保留了规则说明）。

### 现行参数（复核日期 2026-09-21）

| 项目 | 现行规定 |
|---|---|
| 最高额度（基础） | 一人 100 万元；两人及以上共同申请 200 万元（不区分首套/二套） |
| 额度上浮 | 育儿类最高 +50%、住房品质类最高 +30%，两类可叠加，合计封顶 +80%（180 / 360 万） |
| 可贷额度公式 | 账户余额 × 10 + 月缴存额 × 到退休年龄月数 |
| 贷款利率 | 首套：1–5 年（含）2.1%，5 年以上 2.6%；二套：1–5 年（含）2.525%，5 年以上 3.075% |
| 最低首付 | 首套及第二套 20%；保障性住房 15% |
| 贷款期限 | ≤ 30 年；二手楼「期限 + 楼龄」≤ 50 年；年龄 + 期限 ≤ 退休后 5 年且 ≤ 68 岁 |
| 套数认定 | 按购房所在区认定；第三套及以上不予贷款 |
| 购房资格 | 全市已取消限购限售（2024-09 起） |
| 缴存基数 | 2026 年度：下限 2500 元，上限 41697 元；比例单位/个人各 5%–12% |
| 法定退休年龄 | 2025-01-01 起渐进式延迟：男 60→63、原 55 岁女职工 55→58、原 50 岁女职工 50→55，按出生年月查对照表 |
| 商贷参考 | 2026-09 5 年期以上 LPR 3.5%，广州首套主流约 3.0%（LPR−50BP），最低首付 15% |

### 提取

使用本市住房公积金贷款的，提取人均应办理按月还贷，缴存的公积金优先偿还公积金贷款；**按月还贷期间可提取一次账户余额，金额不超过实际支付的首期房款**；还清后每 3 个月可提取一次，直至该套住房累计提取额达到「实际支付的购房本息」。

### 官方来源

- 广州住房公积金管理中心《个人住房公积金贷款服务指南（普通公积金贷款）》（2026-06-08）
- 《广州住房公积金个人住房贷款实施办法》（2026-06-09 起施行）
- 穗公积金中心规字〔2026〕1号（2026-04-30 施行，有效期 5 年）
- 《广州市住房公积金提取管理办法》（穗公积金中心规字〔2023〕5号）及提取服务指南
- 全国人大常委会《关于实施渐进式延迟法定退休年龄的决定》及所附对照表（2025-01-01 施行）

完整链接见应用内「政策参数」页与每次测算结果底部的「政策来源」折叠区。

## 六、隐私

- **不联网**：服务端不调用任何外部接口，前端不引用任何 CDN，无埋点、无遥测、无账号注册。
- **数据只存本地**：全部记录保存在你自己的 SQLite 文件里，密码哈希保存在 `data/auth.json`，容器不向外发任何数据。
- **有访问门禁**：一个自设的口令才是进入条件，未登录时所有数据接口返回 401，页面上也看不到任何内容。
- 适合放在内网使用；如需公网访问请自行加反向代理与 HTTPS（本项目自带的口令只做单层防护，不替代传输加密）。
